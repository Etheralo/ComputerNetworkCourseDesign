# DNS Relay 展示与使用说明

## 1. 展示前检查

在项目根目录打开 PowerShell。Windows 没有 `make` 时，直接执行：

```powershell
py -3 --version
py -3 -m unittest discover -s tests -v
py -3 -m src.dns_relay.demo
```

应显示 19 项测试通过，并输出三个 DNS 分支。真实上游演示前，先确认网络可访问所选 DNS 服务器：

```powershell
Get-DnsClientServerAddress -AddressFamily IPv4
```

不要修改整机 DNS 设置，也不要在尚未确认端口占用时改用 53 端口。

建议准备四个窗口：Relay 日志、PowerShell 查询、Wireshark、
`config/dnsrelay.txt`。

## 2. 六分钟现场流程

### TCP 连续通信（约 1 分钟）

终端 A 执行：

```powershell
py -3 -m src.socket_demo.server --host 127.0.0.1 --port 9000
```

终端 B 执行：

```powershell
py -3 -m src.socket_demo.client --host 127.0.0.1 --port 9000
```

依次输入 `hello`、`第二条消息`、`exit`。指出服务端的
`bind -> listen -> accept -> recv/send -> close` 流程和客户端地址日志。

### DNS 三个分支（约 3 分钟）

终端 A 启动 Relay。先将 `<上游DNS>` 替换为
`Get-DnsClientServerAddress -AddressFamily IPv4` 查到的可达地址：

```powershell
py -3 -m src.dns_relay.server --host 127.0.0.1 --port 5353 `
  --upstream <上游DNS> --upstream-port 53 `
  --table config/dnsrelay.txt
```

终端 B 依次执行：

```powershell
py -3 -m src.dns_relay.query --name local.test --type A
py -3 -m src.dns_relay.query --name blocked.test --type A
py -3 -m src.dns_relay.query --name www.baidu.com --type A
py -3 -m src.dns_relay.query --name local.test --type AAAA
```

预期：第一条返回 `10.0.0.123`；第二条状态为 `rcode=3` 且无 Answer；
第三条日志分支为 `upstream`；第四条即使名称在本地表中也转发，因为本地表只回答 A/IN。

### 字段与可靠性（约 1.5 分钟）

在 Wireshark 中使用显示过滤器：

```text
dns && (udp.port == 5353 || udp.port == 53)
```

抓取 `127.0.0.1:5353` 时选择 **Npcap Loopback Adapter**。抓取公网转发时，
还要同时选择 Wi-Fi 或以太网网卡；否则只能看到其中一段通信。由于 5353
不是标准 DNS 端口，首次捕获后右键数据包选择
**Decode As... -> DNS**，再使用上面的 `dns` 过滤器。

展开 Domain Name System，指出请求/响应 Transaction ID 相同；响应 `QR=1`；
`RD` 被保留；Relay 设置 `RA=1`；本地命中 `ANCOUNT=1`；屏蔽命中
`RCODE=3`。公网查询应出现“客户端 ↔ Relay”和“Relay ↔ 上游”两段 UDP 通信。

执行 `py -3 -m unittest discover -s tests -v`，重点展示截断包、上游超时、
错误上游 ID 和并发用例均通过。说明每个转发任务使用独立 UDP Socket，
线程池限制并发数量。

### 总结（约 30 秒）

说明边界：这是本地规则加上游转发的 Relay，不是完整递归 DNS；当前不实现缓存、
DNS over TCP 和本地 AAAA 记录。

## 3. 抓包与截图

开始查询前启动 Wireshark。TCP、本地 A 和 NXDOMAIN 选择
**Npcap Loopback Adapter**；上游转发同时选择 Loopback 和当前联网网卡。
至少保存四张截图：TCP 收发、本地 A Answer、NXDOMAIN、上游转发。
截图要展开关键字段并对 Transaction ID 做标注。保存方式和文件命名见
[captures/README.md](captures/README.md)。

如 5353 报端口占用，可传入其他端口：

```powershell
py -3 -m src.dns_relay.server --host 127.0.0.1 --port 15353 `
  --upstream <上游DNS> --upstream-port 53 `
  --table config/dnsrelay.txt
```

15353 也是非标准 DNS 端口，抓包后同样需要
`Decode As... -> DNS`，查询工具需要加 `--port 15353`。

如公网查询返回 SERVFAIL，先检查 Relay 日志中的上游地址和耗时，再确认
Windows 防火墙是否允许 UDP/53；本地 A 与 NXDOMAIN 分支不依赖公网，
应仍能正常工作。
